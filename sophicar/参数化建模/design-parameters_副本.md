## 响应式设计

### 断点设计
| 断点 | 布局变化 |
|------|----------|
| 1200px+ | 双栏布局 (主内容 + 场景选择) |
| 768px-1199px | 单栏布局 (场景选择在上) |
| < 768px | 单栏布局、导航垂直排列、场景卡片单列 |

### 适配策略
- 使用 CSS Grid 和 Flexbox 实现响应式布局
- 媒体查询适配不同屏幕尺寸
- 流动式布局，确保在各种设备上的良好显示

## 实现注意事项

1. **像素级还原**: 严格按照设计稿的尺寸、间距、圆角等参数实现
2. **性能优化**: 使用 SVG 格式图片，减少文件大小
3. **可访问性**: 确保所有交互元素都有适当的状态反馈
4. **兼容性**: 确保在主流浏览器中正常显示
5. **代码规范**: 保持代码结构清晰，注释完善
